Recursive void methods often have structure like this, with multiple statements in the recursive case:

void recursion(int input) {
  if (/* base case */) {
    // do something simple
  } else {
    // do stuff
    recursion(smallerInput);
    // do more stuff
  }
}

Recursive methods that return values have a different structure because they can return only one value. You'll need to build the answer before or inside the return statement.

✗   NOT POSSIBLE — code after return is never reached 
int recursiveMethod(int input) {
  if (/* base case */) {
    return somethingSimple;
  } else {
    return something;                     // method ends here
    return recursiveMethod(smallerInput); // never reached
    return something;                     // never reached
  }
}
The answer must be built inside the return statement, like Jasmine's: return 1 + 2 * segmentsInTree(n - 1);

Word processing programs count the number of words and letters in documents. One way to count the number of letters in a phrase is to use a recursive method.

The key pattern for string recursion: isolate the first character, do something with it, then recurse on the rest of the string.

5.

The phrase "in the course of human events" has 24 letters. How many letters are there in the phrase "When in the course of human events"?

6.

Recursion always needs a base case to stop the method from calling itself forever. What sort of base case might we use for this situation?

7.

Write a letterCount method that takes a String as input and returns the total number of letters, not counting spaces. It should return 28 for "We the people of the United States".

Useful String methods:

str.length() — number of characters

str.substring(0, 1) — first character as a String

str.substring(1) — everything after the first character

str.equals(" ") — check if a String is a space

Hint
Each recursive call isolates the first character: str.substring(0, 1). Is it a space? If not, count it. Then recurse on str.substring(1). What's the base case — when is the string simple enough to answer immediately?
8.

Write a joinWords method. It takes a String[] and an index, and returns all the words joined together with spaces:

String[] words = {"We", "the", "people", "of", "the", "United", "States"};
println(joinWords(words, 0));
// → "We the people of the United States"

Same pattern: isolate the first element (words[index]), combine it with the recursive call on the rest (joinWords(words, index + 1)).

Useful:

words.length — number of words in the array

words[index] — word at position index

Hint: what's the base case?
When index reaches the last word (words.length - 1), just return that word — nothing left to combine with. Or when index == words.length, return an empty string "".

Here's a reverseString method. Read it carefully, then answer the questions below.

String reverseString(String str) {
  if (str.length() == 0) return "";
  return reverseString(str.substring(1)) + str.substring(0, 1);
}
