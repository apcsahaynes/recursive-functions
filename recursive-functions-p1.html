Thinking Out Loud

Morgan and Jasmine discuss the code they created.

Morgan: I noticed a pattern in the table. Each number of segments is one less than a power of 2.
Jasmine: What does your code look like?
Morgan: I used a for loop to build the power of 2, then subtracted 1 at the end: 
int segmentsInTree(int n) {
  int answer = 1;
  for (int i = 1; i < n; i++) {
    answer = answer * 2;
  }
  return answer - 1;
}
Morgan: At the end, the return statement sends the final value. I put the last math operation there.
Jasmine: Wow. Mine looks a lot different! I made the code look like the code for tree.
Morgan: Interesting... but I don't get it.
Jasmine: Look back at the code for tree. We used recursion. We drew a segment, turned, called tree to draw a smaller tree, turned again, and then called tree again to draw another, smaller tree.
Morgan: Cool! We can think about how that algorithm works to write segmentsInTree recursively. But we can ignore all the drawing and turning parts, right? Let me give this a shot.
Jasmine: Right! And don't forget: base cases are important!

You've built and worked with recursive void methods. Recursion can also be used in methods that return values.

In Java, once a return statement executes, the method ends immediately. No further code runs after a return.
4.

If you haven't yet, write a recursive method that returns the number of segments in a tree of level n. Here's Jasmine's code:

int segmentsInTree(int n) {
  if (n == 1) {
    return 1;
  } else {
    return 1 + 2 * segmentsInTree(n - 1);
  }
}
